Local-first blacklist controls

Rules are stored in chrome.storage.local and never sent to external servers.

Development

Rule type guide

Keyword / phrase
Hides a conservative container around text containing the pattern.
CSS selector
Hides elements matching a selector such as .ad-card.
Domain
Blocks requests to a domain with Declarative Net Request and hides the page body when the current hostname matches.
Regex
Advanced matching for text nodes. The MVP rejects long or risky-looking patterns.
